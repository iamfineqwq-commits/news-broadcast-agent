# 📰 news-broadcast-agent · AI 智能新闻助理

**"新闻报通"** 是一个基于 [n8n](https://n8n.io/) 构建的自动化 AI Agent。它能追踪最新的 AI 动态，对新闻进行**重要性评分**和**领域分类**，并结合你的飞书日程，每天早晨为你推送一份重点突出、分区清晰、可选择性阅读的智能早报。当没有重大新闻时，它还会贴心地建议你放松身心。

## 🌟 核心价值

- 📡 **信息聚合**：定时从 4 个 AI 新闻源（新智元 / AIBase / 腾讯科技 / 量子位）抓取当日新闻，清洗、摘要后存入飞书多维表格
- ⭐ **重要性评分**：每条新闻由 LLM 按 1-5 分评估重要性并给出理由，早报中高分新闻置顶为「今日重点」，推送有据可依
- 🗂️ **领域分类**：新闻按 7 个固定领域分类，早报按领域分区渲染，可快速定位感兴趣的板块
- 📅 **日程感知**：同步未来 7 天的飞书日历，结合日程忙闲给出阅读与排期建议
- 🤖 **智能决策**：由 DeepSeek 驱动的 AI Agent 自主决定何时查询新闻、何时查询日程
- 💬 **即时推送**：以 Markdown 互动卡片形式，通过飞书群机器人每日定时推送

## 📬 每日早报长什么样

早报卡片按以下结构生成：

1. **🚀 今日重点** —— 重要性 ≥ 4 分的新闻置顶完整展示（标题 / 日期 / 媒体 / 摘要 / ⭐评分及理由 / 链接）
2. **🗂️ 分领域速览** —— 其余新闻按领域分组，一行一条精简展示
3. **📅 近期日程概览** —— 未来几天的日程安排
4. **💡 综合建议与排期参考** —— 按日程忙闲 × 新闻价值分档输出：日程满 → 建议存档稍后读；有空档且有干货 → 推荐精读某条（引用评分理由）；新闻一般 → 建议放松；无新闻 → 直接推荐具体的放松活动

没有新闻的日子，它会告诉你："今天 AI 领域风平浪静"，然后劝你出门走走。

## 🏗️ 系统架构

项目由两个 n8n 工作流组成，通过同一张飞书多维表格衔接：

```
┌─────────────────────────┐         ┌──────────────────────────┐
│  自动获取新闻流（采集）    │         │  推送新闻bot（早报生成）    │
│                         │         │                          │
│  每天 07:00 / 21:00 触发  │ 写入 →  │  每天 08:00 触发           │
│  4 个 RSS 源并行抓取      │         │  AI Agent (DeepSeek)      │
│  字段映射 + 日期标准化     │         │   ├─ 工具：查多维表格       │
│  仅保留当日新闻           │  飞书    │   └─ 工具：查飞书日历       │
│  LLM 摘要 + ⭐重要性评分   │  多维    │  生成 Markdown 早报        │
│  + 🗂️领域分类            │  表格    │  飞书群机器人 Webhook 推送  │
└─────────────────────────┘         └──────────────────────────┘
```

时间设计上：晚间 21:00 采集入库的新闻，第二天早上 8:00 的早报即可覆盖（推送时查询「今天或昨天」的新闻）。

## ✨ 功能特性

- **双工作流分工**：采集与推送解耦，采集失败不影响早照常推送
- **重要性评分标准**（防拍脑瓜）：
  - `5` 行业级重大事件：头部公司重磅发布、颠覆性技术、重大政策
  - `4` 重要进展：知名产品更新、较大金额投融资
  - `3` 一般动态：常规产品迭代、一般性报道
  - `2` 边缘资讯：传闻、未证实消息、垂直领域动态
  - `1` 低价值：标题党、软文、营销内容
- **固定领域枚举**（保证统计口径一致，禁止模型自创分类）：`大模型发布` / `产品与应用` / `芯片与硬件` / `投融资` / `政策与监管` / `学术研究` / `行业动态`
- **类型兜底**：字段映射对评分输出做了字符串兜底，防止模型输出数字类型导致写表失败
- **数据标准化**：自动处理日期格式，确保各数据源格式统一
- **无代码/低代码编排**：全部逻辑通过 n8n 可视化搭建，易于修改和扩展

## 🛠️ 技术栈

- [**n8n**](https://n8n.io/)（v2.31.4+）：工作流自动化编排引擎
- [**DeepSeek API**](https://platform.deepseek.com/)：新闻摘要、评分、分类与早报生成
- [**飞书开放平台**](https://open.feishu.cn/)：
  - **多维表格 (Bitable)**：新闻数据的存储与查询
  - **日历 API**：日程查询
  - **群自定义机器人 Webhook**：早报卡片推送

## 🚀 快速开始

### 前置要求

1. 可用的 n8n 实例（推荐 `v2.31.4` 或更高）
2. 飞书企业自建应用（App ID / App Secret），并授权：
   - `bitable:record:read` / `bitable:record:write`（读写多维表格）
   - `calendar:event:read`（读取日历）
3. 一张飞书多维表格作为新闻仓库，字段如下：
   | 字段                     | 类型               |
   | ---------------------- | ---------------- |
   | 标题 / 日期 / 内容 / 链接 / 媒体 | 文本               |
   | 重要性                    | 文本（存 1-5 的数字字符串） |
   | 重要性理由                  | 文本               |
   | 领域                     | 单选（预录 7 个分类）或文本  |
4. 一个飞书群自定义机器人（获取 Webhook 地址）
5. 有效的 DeepSeek API Key

### 导入与配置

1. **下载工作流文件**：本仓库根目录的 `自动获取新闻流.json`（采集）和 `推送新闻bot.json`（推送），在 n8n 中分别 **Import from File** 导入
2. **配置凭据**（占位符替换）：
   - 两个工作流中的 Lark 节点 → 新建 `Lark Tenant Token` 凭据，填入 App ID / App Secret
   - DeepSeek 模型节点 → 填入 DeepSeek API Key
3. **替换占位符**（文件中已脱敏，全部形如 `YOUR_XXX`）：
   - `YOUR_BITABLE_APP_TOKEN` / `YOUR_BITABLE_TABLE_ID` → 你的多维表格地址中的 token 和数据表 ID
   - `YOUR_FEISHU_CALENDAR_ID` → 你的日历 ID
   - `YOUR_FEISHU_BOT_WEBHOOK_TOKEN` → 群机器人 Webhook 地址
4. **按需调整触发时间**：采集流默认每天 7:00 / 21:00，推送流默认每天 8:00
5. **手动执行采集流一次**，确认新闻正常写入多维表格；再手动执行推送流，确认群里收到卡片
